voir remote probe

Open this over the same secure origin as voir (tailnet HTTPS) on the phone, or from a desktop for a keyboard sanity check. Nothing is sent anywhere — use Copy log and paste it back.

1 · keydown — pair the ring as a keyboard/mouse, then press every button

waiting for a key…

Swallow on keeps the page from scrolling/tabbing while you probe. Turn it off to check whether a button reaches the browser's own handling (e.g. a media key).

2 · mouse / wheel (a scrolling ring is often a wheel)

no wheel events yet

3 · media session — which consumer-key commands arrive

idle — media keys only route while a session is active

4 · Web Bluetooth GATT — only if the ring is not bonded as HID

Android hands a bonded HID device to the HID profile, so it usually won't show here. If so: unpair it, or use nRF Connect on the phone to read the GATT table.
